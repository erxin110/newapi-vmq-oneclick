# NewAPI + V免签一键部署助手

面向 Windows 用户的 NewAPI 与 V免签一键部署工具。

## 主要功能

- 检测服务器环境
- 一键部署 NewAPI
- 一键部署 V免签
- 自动配置 HTTPS
- 自动配置 NewAPI 支付接口
- 检查部署状态
- 提供清理和重新部署功能

## 下载

请前往本仓库右侧的 Releases 页面下载最新版本。

## 系统要求

- Windows 10 或 Windows 11 64 位
- 一台可通过 SSH 登录的 Linux 云服务器
- 已解析到服务器的 NewAPI 域名
- 已解析到服务器的 V免签域名

## 使用说明

1. 下载并运行 Windows 客户端。
2. 输入服务器 IP、SSH 登录信息及域名。
3. 检测服务器环境。
4. 购买并输入有效授权码。
5. 按程序提示完成部署。

## 安全说明

服务器密码和部署记录保存在用户自己的电脑中，不会包含在程序安装文件中。

请不要将 SSH 密码、私钥或授权码发送给其他人。

## Windows 安全提示

当前版本可能尚未进行 Windows 代码签名。首次运行时，Windows
可能显示“未知发布者”或 Microsoft Defender SmartScreen 提示。

请仅从本仓库的 Releases 页面下载，并核对 SHA-256。
